# Розклад ЖТУ (ZTU Schedule)

Android додаток для перегляду розкладу занять Житомирської політехніки з підтримкою віджета для головного екрана, темної теми «Sleek Interface» та автоматичного відстеження поточного дня.

## Як отримати APK на телефон через GitHub Actions

1. Запустіть репозиторій на GitHub (експортуйте або синхронізуйте проєкт з Google AI Studio).
2. Відкрийте репозиторій на GitHub у браузері вашого телефону.
3. Перейдіть у вкладку **Actions**.
4. Виберіть workflow **Build Android APK** та натисніть **Run workflow** (або просто зробіть будь-який commit чи push).
5. Після завершення збірки натисніть на виконаний запуск:
   - Внизу в розділі **Artifacts** завантажте **ZTU-Schedule-Release-APK**.
   - Розархівуйте та встановіть APK на свій телефон.
6. Також при створенні Git-тегу (наприклад, `v1.0.0`) готова APK автоматично опублікується у розділі **Releases**.
